# 增肌助手（MuscleUp）

专为瘦子增肌设计的安卓健身 App。所有数据仅保存在手机本地，无需联网、无需注册。

**安装包：** [`release/MuscleUp-v1.1.1.apk`](release/MuscleUp-v1.1.1.apk)（Android 7.0 及以上）

## 功能

| 模块 | 内容 |
| --- | --- |
| 首页 | 体重进度、今日热量/三大营养素环形图、今日训练、饮水打卡、本周统计、每日小贴士 |
| 训练 | 6 套计划（新手全身 A/B、上下肢分化、PPL、居家哑铃、零器械徒手、肩臂专项）；训练记录器（重量/次数/勾选完成、自动组间休息倒计时+震动、根据上次表现给出加重建议、估算 1RM）；自由训练；训练历史、近 8 周训练频率、各部位训练量分析、个人最佳 PR 与力量等级 |
| 动作库 | 57 个动作，按部位/器械筛选，含步骤、要点、常见错误和个人进步曲线 |
| 饮食 | 按 Mifflin-St Jeor 公式计算热量盈余与蛋白/碳水/脂肪目标；92 种常见中式食物与外卖；自定义食物；按餐记录；复制前一天；4 套一日增肌食谱、7 个增肌奶昔/快手餐 |
| 身体 | 体重曲线（含目标线）、每周增重速度与饮食调整建议、5 项围度记录与曲线、BMI、海军公式体脂率、睡眠记录 |
| 工具 | 组间休息计时器、1RM 计算器（附训练重量表）、杠铃片配重与热身组、补剂指南、增肌知识库（10 篇）、15 个成就徽章 |
| 悬浮计时 | 显示在其他 App 上层的训练计时悬浮窗：拖动移动、轻点暂停/继续、长按收起；「休」一键组间休息倒计时（结束震动）；通知栏同步显示并可操作；结束后自动保存训练时长，统计今日/本周/本月与近 7 天时长 |
| 提醒 | 训练/早餐/加餐/喝水/睡觉 每日定时通知 |
| 数据 | 导出备份（分享文本）、粘贴恢复、清除数据 |

## 构建

需要 JDK 17+ 和 Android SDK（platform 35）。

```bash
./gradlew :app:assembleRelease      # 输出 app/build/outputs/apk/release/app-release.apk
./gradlew :app:testDebugUnitTest    # Robolectric 端到端流程测试
```

签名密钥位于 `keystore/`（便于后续版本覆盖安装）。如果要公开分发，请换成自己的密钥并不要提交到仓库。
