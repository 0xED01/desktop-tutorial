# MBTI 性格测试（Android）

- 60 道原创迫选题（E/I、S/N、T/F、J/P 各 15 题），左右选项倾向已平衡
- 4 级程度作答，按维度计分，显示百分比与偏好清晰度（轻微/中等/明显/非常明显）
- 平分时按 MBTI 惯例判为 I/N/F/P
- 16 型说明：概述、优势、盲点、认知功能顺序、人群比例、常见领域
- 进度自动保存、历史记录、本地存储，无网络权限

非官方 MBTI® 测评，仅供自我了解。

构建：`./gradlew assembleRelease`（需 Android SDK 34），APK 位于 `app/build/outputs/apk/release/`。
