# 🪙 钱来账本

低价采购、高价转卖的利润账本，记录从各电商平台进货到卖出的每一笔。只有一个 `index.html` 文件，用浏览器直接打开就能用，不用安装，也不用联网。

## 怎么用

**安卓手机**：下载仓库里的 [`QianLaiLedger.apk`](QianLaiLedger.apk) 安装即可。从旧版「转卖账本」升级时直接覆盖安装，数据会保留（需要在手机上允许「安装未知来源应用」）。安卓 7.0 及以上可用。

**电脑或其他手机**：
1. 双击 `index.html` 用浏览器打开（手机、电脑都可以）。
2. 点 **＋**（手机在底栏中间，电脑在右下角）记下买入，再点货单上的 **卖出** 记下卖出，利润会自动算好。
3. 第一次打开可以点「先看看示例数据」看看效果，之后在「设置 → 清空所有数据」里清掉。

## 功能

- **记一单**：填商品、进货平台、单价、数量、运费、渠道名称（代买人）、渠道费用（找人代拍给的红包等）、返利/返现、预期售价、订单号、分类和备注，保存前就能看到到手成本和预计利润。
  - 渠道名称下面会列出最近用过的代买人，点一下就填上，不用每次重新输入。
  - 「保存，再记一单」适合一次记很多单，会沿用上一单的平台和日期。
  - 商品名旁边有「历史商品」按钮，点开可以搜索、选择以前录过的商品，自动带出名称和上次的进货平台、买入价、分类、预期价。输入商品名时不会弹出下拉列表。
  - 数量可以点 −/＋ 调整；分类、订单号、备注收在「＋ 分类、订单号、备注」里，用到时再展开。
- **一键卖出**：选出货平台、填售价，会按设置好的费率自动算手续费，并显示利润、利润率和持有天数。
  - 售价下面有快捷价格：预期价、**回本价**（卖这个价刚好不亏）、回本价 +10% / +20% / +30%，点一下就填好。
  - 会记住你上次用的出货平台，以及每个平台平时是「待到账」还是「已到账」，下次自动选好。
  - **可以只卖一部分**：比如买了 5 件卖掉 2 件，会自动拆成两条记录，运费、渠道费用和返利按件数分摊。
- **货款到账**：卖出时可以选「待到账」或「已到账」。没到账的单会显示待收的到账金额，等钱到了在货单上点 **确认到账** 即可。
  - 货单里有「待到账」分类，可以一键全部确认到账。
  - 概览会显示所有待到账货款的总额和单数，超过 7 天没到账会标黄提醒。
- **状态流转**：在途 → 已到货 → 已上架 → 已售出。也可以标记退货，退货的单不计入统计。
- **待处理**：概览页会列出待到账和在途的单，直接点「到账」「到货」一键处理，压货超期也会提醒。
- **日历**：右上角「日历」按钮打开。
  - 每个月一张日历，每天的格子里显示当天净利润，颜色越深赚得越多；小圆点表示当天有进货、到账或杂费。
  - 顶部显示本月净利润、卖出单数和最赚的一天，‹ › 切换月份。
  - 点某一天，下面列出当天的净利润、卖出、进货、到账金额，以及当天卖出、进货、到账的每一单和杂费，单子可以直接操作。
  - 月报页也有「按日看」入口。
- **概览**：可以切换单日、本月、上月、今年、全部。选「单日」后可以用 ‹ › 一天天翻，也可以直接选日期。概览里能看到以下数据：
  - 净利润、销售额、利润率、胜率、平均周转天数和进货支出
  - 当前压货占用的资金和压货的预计利润
  - 压货超期提醒（天数可以在设置里改）
  - 近 12 个月净利润柱状图，点柱子能看当月明细
  - 按进货平台和出货平台统计的利润，以及最赚和亏钱的单
  - 按代买人统计：每人帮你买了几件、给了多少渠道费、卖出赚了多少，点名字可以看他经手的所有单
- **货单列表**：可以按状态（未出手、在途、在库、已上架、已售出、压货超期、已退货）筛选，也可以按平台、月份筛选，或者用关键字搜索，并按时间、利润、成本排序。
  - 每单右侧有当前最常用的按钮（卖出 / 到货 / 确认到账），点一下就完成。
  - 点任意一单会弹出明细（成本、卖出、利润一目了然）和全部操作：编辑、「再来一单」、撤销卖出、退货、删除等。删除、到账、到货都可以撤销。
- **月报**：按年份显示每个月的销售额、卖出成本、手续费和运费、毛利、杂费、净利润、利润率、卖出件数、进货支出和进货件数，并有全年合计，可以导出 CSV。
- **杂费**：在「设置 → 杂费」里进入，记包装、快递、会员费等不属于某一单的开销，也可以记其他收入。这些都会计入月度净利润。
- **设置**：
  - 进货平台、出货平台、杂费类型都是一个个列出来的，点「＋ 添加」加一个，点 × 或「删除」删一个（删了能撤销，以前的记录不受影响）
  - 每个出货平台旁边可以填手续费率，改完立即生效
  - 可以选「红色盈利/绿色亏损」或「绿色盈利/红色亏损」
  - 支持自动深色模式

## 计算口径

- 到手成本 = 买入单价 × 数量 + 买入运费 + 渠道费用 − 返利/返现
- 到账金额 = 卖出单价 × 数量 − 平台手续费（比如卖 6800、平台不收手续费，到账就是 6800）
- 卖出运费是你自己另外付的，**不从到账金额里扣**，但会算进利润
- 利润 = 到账金额 − 卖出运费 − 到手成本；利润率 = 利润 ÷ 到手成本
- 月度利润按**卖出日期**算进当月，进货支出按**买入日期**算进当月。
- 净利润 = 卖货毛利 − 杂费支出 + 其他收入

## 数据安全

数据只保存在当前浏览器的本地存储（localStorage）里，不会上传。换浏览器、换设备或清理浏览器数据之前，请先在 **设置 → 导出备份** 导出 JSON 文件，之后可以用「导入备份」恢复。货单也可以导出成 CSV，用 Excel 打开。

> 安卓 App 的数据保存在 App 内部，**卸载 App 会清空数据**，卸载前请先导出备份。升级新版本时直接覆盖安装即可，数据会保留。

## 打包安卓 APK

`android/` 目录是一个很薄的 WebView 外壳，直接加载 `index.html`，并补上了导出文件、导入备份和返回键。不需要 Gradle，装好 JDK 和 Android SDK（`platforms;android-35`、`build-tools;35.0.0`）后运行：

```bash
ANDROID_HOME=/path/to/android-sdk android/build.sh
```

运行后会在仓库根目录生成 `QianLaiLedger.apk`。修改 `index.html` 后重新打包即可，发新版时可以用 `VERSION_CODE=2 VERSION_NAME=1.1` 递增版本号。包名 `com.zhuanmai.ledger` 和签名文件 `android/release.jks` 都不要改：换了签名就不能覆盖安装，只能卸载重装，数据会丢。
