# 安睡 · 改善睡眠的安卓 App

**安装包：[`release/AnShui.apk`](release/AnShui.apk)**（Android 8.0 及以上，约 50 KB，无广告、无联网、数据只存在手机上）

## 为什么它真的有用

安睡没有用“助眠音乐 + 鸡汤”的套路，而是把**失眠认知行为疗法（CBT-I）**做成了每天可执行的步骤。CBT-I 是各国睡眠指南推荐的慢性失眠首选治疗，约 70%-80% 的人明显改善，且效果比安眠药更持久。

| 功能 | 作用 |
| --- | --- |
| **睡眠日记** | 每天早上 1 分钟，自动算出实际睡眠时长和**睡眠效率**（睡着 ÷ 在床） |
| **睡眠窗口计划**（睡眠限制疗法） | 记录满 5 晚后，按你真实的平均睡眠算出上床/起床时间；之后每周按睡眠效率自动建议调整（≥90% 延长 15 分钟，<85% 缩短 15 分钟，下限 5.5 小时） |
| **自定义上床时间** | 在“今晚 → 设置”里可以自己选上床时间（覆盖自动计算），提醒会跟着变；随时可以“恢复自动”。躺床少于 5 小时或超过 10 小时、或比睡眠窗口多躺时会提示 |
| **每日提醒** | 睡前 8 小时咖啡因截止、睡前 1 小时放松、上床时间、起床时间（配合晒太阳和填日记） |
| **固定起床闹钟** | 一键在系统闹钟里设置每天同一时间起床 |
| **放松训练** | 4-7-8 呼吸、每分钟 6 次慢呼吸、渐进式肌肉放松、认知洗牌（打断胡思乱想）、写下烦恼。练习时自动调暗屏幕，阶段切换会振动，可闭眼跟做 |
| **助眠声音** | 实时合成白噪音 / 粉红噪音 / 棕色噪音 / 海浪，锁屏持续播放，定时 1 分钟淡出 |
| **睡眠指南** | 刺激控制、20 分钟法则、光照、咖啡因与酒精、卧室环境、认知调整、何时该看医生 |

## 怎么用（照做最重要）

1. **第 1 周**：每天早上填睡眠日记，照常睡，不用改变。
2. **第 2 周起**：在“今晚”页点“开始计划”，严格按睡眠窗口上床和起床——**起床时间每天固定，周末也一样**。
3. 困了才上床；躺下约 20 分钟睡不着就起来，到昏暗处做无聊的事，困了再回去。
4. 每周回到“今晚”页按建议调整窗口。前 1-2 周白天可能更困，这是正常的，通常 3-6 周明显改善。

> 有双相情感障碍、癫痫、睡眠呼吸暂停、怀孕，或需要驾驶/操作机械的人，请先咨询医生再做睡眠限制。本 App 是自助工具，不能替代医疗诊断。

## 安装

把 `release/AnShui.apk` 传到手机上打开，按提示允许“安装未知来源应用”。首次打开请允许通知，以便收到提醒。部分国产系统需要在设置里允许 App 自启动/后台运行，提醒才会准时。

## 从源码构建

需要 JDK 17+ 和 Android SDK（platform 34）：

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease   # 输出 app/build/outputs/apk/release/app-release.apk
```
