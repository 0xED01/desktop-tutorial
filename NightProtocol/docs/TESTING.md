# 测试方案与状态

状态图例：**✅ 已验证**（本环境实际执行通过）· **⬜ 未验证**（未执行）· **❌ 失败**（执行后未通过）

> 本次交付的构建环境没有模拟器（无 KVM）也没有真机，因此**所有设备相关项目均为“未验证”**。
> API 在文档上可用 ≠ 在某一厂商真机上可用。

### 在有 KVM 的电脑上运行 A9/A10

```bash
sdkmanager "emulator" "system-images;android-35;google_apis;x86_64"   # 也请分别测试 34 与 36
avdmanager create avd -n np35 -k "system-images;android-35;google_apis;x86_64"

scripts/setup_device_owner.sh        # 新模拟器无账户，可直接设置
scripts/emulator_e2e.sh              # 输出逐项 PASS/FAIL，退出码非 0 表示有失败
```

## B. 手动测试（必须在真机的“测试封锁”中执行）

App 内“正式启用前检查”与下表一一对应。自动项由 App 在测试封锁中实测记录；“手动”项只有用户本人能确认，
App 只允许在至少一次**真正进入 Lock Task** 之后标记。任何一项为“失败”或“未验证”，严格模式都无法启用；
启用后若手动标记某项失败，严格模式会被自动关闭。

| # | 项目 | 步骤 | 判定 | 状态 |
|---|---|---|---|---|
| B1 | Device Owner | 执行配置命令后打开 App | “Device Owner：是” | ⬜ |
| B2 | 应用暂停生效 | 测试封锁 2 分钟 | 检查项自动记录；被暂停应用图标变灰，点击弹出“已被管理员停用” | ⬜ |
| B3 | 真正进入 Lock Task | 同上 | 自动记录 `LOCKED`；`PINNED`（屏幕固定）判为失败。上滑/返回/最近任务/下拉无法离开 | ⬜ |
| B4 | 自动退出与恢复 | 等待测试到期 | Lock Task 退出、全部应用恢复、回到原桌面（自动记录） | ⬜ |
| B5 | 来电（亮屏） | 测试封锁中、亮屏停在锁定界面，用另一部手机拨入 | 来电界面/浮窗出现，可接听、通话、挂断，挂断后回到锁定界面 | ⬜ |
| B6 | 来电（熄屏/锁屏） | 熄屏后拨入 | 全屏来电界面，可接听 | ⬜ |
| B7 | 拨打电话 | 锁定界面「电话」 | 拨号器打开，可拨出并挂断，返回锁定界面 | ⬜ |
| B8 | 紧急拨号流程 | 锁定界面「紧急呼叫」；锁屏“紧急呼叫”；长按电源键菜单 | 紧急拨号界面能打开。**不要真实拨打紧急号码** | ⬜ |
| B9 | 电源键 | 短按熄屏、再按唤醒、解锁；长按出现电源菜单 | 全部正常，解锁后仍在锁定界面 | ⬜ |
| B10 | 闹钟 | 测试封锁前设 2 分钟后闹钟 | 锁定中按时响铃，可关闭/贪睡，返回锁定界面 | ⬜ |
| B11 | 恢复码 | 测试封锁中用恢复码解除 | 自动记录通过；日志含原因 | ⬜ |
| B12 | ADB 恢复 | 测试封锁中执行 `scripts/adb_recover.sh` | 自动记录通过 | ⬜ |
| B13 | 定时开始/结束 | 将计划设为 2 分钟后开始、5 分钟后结束 | 到点锁定、到点恢复；日志中调度方式为 `exact@…` | ⬜ |
| B14 | 重启（锁定中） | 锁定期间重启 | 开机解锁后回到锁定界面；被暂停应用仍暂停 | ⬜ |
| B15 | 重启（跨越结束时间） | 07:29 关机，07:31 开机 | 开机后自动恢复 | ⬜ |
| B16 | 时间/时区修改 | 在白天修改时区使当前时间落入窗口 | 立即锁定；改回后恢复 | ⬜ |
| B17 | APK 覆盖安装 | 锁定期间 `adb install -r -t` | 更新后状态被重新核对，仍锁定 | ⬜ |
| B18 | 进程被杀 | 锁定期间 `adb shell am force-stop` 后点亮屏幕 | 应用暂停保持；下次触发源到来时 Kiosk 恢复（记录实际延迟） | ⬜ |
| B19 | 厂商后台清理 | 锁定期间使用系统“一键清理” | 记录是否影响 07:30 恢复 | ⬜ |
| B20 | 睡眠中禁止修改 | 窗口内尝试修改计划/关闭严格模式 | 被拒绝 | ⬜ |
| B21 | 无线紧急警报 | 若设备支持“测试警报”则触发 | 锁定中警报可见 | ⬜ |

## C. 判定纪律

- 只有实际看到结果才标“已验证”；没跑就是“未验证”；跑了不符合预期就是“失败”，并在日志中保留原因。
- 一台设备的结果不能推广到其他机型/ROM 版本。系统 OTA 后应重新执行 B 组。
