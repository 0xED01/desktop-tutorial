# 初级会计实操（安卓 App）

面向初级会计职称考试的离线练习 App。安装包：仓库根目录 `KuaijiShicao-v1.0.apk`。

## 功能
- **分录实操**：100 笔业务分录，覆盖流动资产、非流动资产、负债、所有者权益、收入费用利润、成本核算、政府会计；选科目 + 填金额，自动判分，标出错行，支持多步分录、提示、参考答案与解析
- **刷题**：262 道题（初级会计实务 + 经济法基础），章节练习（记忆进度）、随机 20 题、限时模拟考试（百分制）、错题本、收藏
- **知识点**：按章节整理的考点速记，支持全文搜索
- **工具**：会计科目表、折旧、材料成本差异、毛利率法/售价金额法、约当产量法、增值税、利润、银行存款余额调节表、个税计算
- 考试倒计时、学习统计、深色模式；数据仅保存在本机

## 构建
需要 JDK 和 Android SDK（platforms;android-34、build-tools;35.0.0）：

```bash
ANDROID_HOME=/path/to/android-sdk ./build.sh
```

页面代码在 `app/assets/www/`，题库数据在 `app/assets/www/data/`。`release.keystore` 用于签名，保留它才能覆盖安装后续版本。
